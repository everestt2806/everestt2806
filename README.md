## Highlight Project

### FlowSeeker

**FlowSeeker** is a VS Code extension for AI-assisted software development.

It helps AI coding agents find the right context before editing code. Instead of asking an agent to blindly explore an entire repository, FlowSeeker focuses on identifying the files, symbols, routes, configs, schemas, services, variables, and code snippets that are most relevant to a specific task.

The goal is to help AI agents reduce unnecessary exploration, avoid noisy context, and make safer edits.

Core ideas behind FlowSeeker:

* Task-aware context discovery
* Minimal and relevant context packing
* File, symbol, route, config, schema, and service detection
* Context reasoning before editing
* Safer workflows for AI coding agents
